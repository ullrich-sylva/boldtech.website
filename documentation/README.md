# BOLD TECHNOLOGY AND ENGINEERING SARL

Site vitrine officiel de l'entreprise BOLD TECHNOLOGY AND ENGINEERING SARL, avec backend Node.js.

## Stack Technique
- Frontend : HTML, CSS (Custom Design System), JavaScript Vanilla
- Backend : Node.js, Express
- Fonctionnalités : Formulaire de contact fonctionnel via Nodemailer (SMTP)

## Installation Locale
1. Cloner le projet.
2. Faire `npm install` pour installer les dépendances.
3. Créer un fichier `.env` avec vos identifiants SMTP (voir `server.js`).
4. Lancer le projet avec `node server.js`.
